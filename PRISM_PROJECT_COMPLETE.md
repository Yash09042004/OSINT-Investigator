## 🔍 What is PRISM?

**PRISM** is an advanced Open Source Intelligence (OSINT) automation platform designed to streamline and enhance digital investigations. With over 200 integrated data sources and a modern, intuitive purple gradient interface, PRISM makes complex intelligence gathering simple and efficient.

### Core Features
- 🌐 200+ OSINT data source integrations
- 🎨 Modern purple gradient UI with dark/light themes
- 📊 Multiple export formats (CSV, Excel, JSON, GEXF)
- 🔄 Intelligent correlation engine with YAML rules
- 🐳 Docker deployment support
- 💻 Web UI and CLI interfaces
- 🔒 Privacy-focused local processing
